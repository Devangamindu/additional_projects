# Additional RTL Projects

## Overview

A collection of additional RTL design projects developed in Verilog HDL while strengthening my understanding of digital design, sequential logic, finite state machines, memory structures, and control logic.

These projects complement my major RTL and FPGA projects by covering different digital design concepts and implementation techniques.

## Projects

### Advanced Traffic Controller
Designed an FSM-based traffic control system with multiple operating states and control conditions.

### FIFO Design
Implemented FIFO structures for buffering data between producer and consumer logic, including read/write pointer and full/empty control logic.

### RAM Design
Implemented a small synchronous/asynchronous memory structure in Verilog for understanding memory read and write operations.

### Sequence Detectors
Implemented sequence detector FSMs for detecting predefined serial bit patterns.

Examples include:

- 1101 sequence detector
- 1011 sequence detector
- 111 sequence detector

### Shift Registers
Implemented shift-register based designs for serial data movement and storage.

## Concepts Covered

- Finite State Machines (FSM)
- Sequential Logic
- Combinational Logic
- Counters
- Registers
- Shift Registers
- FIFO Architecture
- RAM Design
- Sequence Detection
- Control Logic

These projects were developed as part of my continuous RTL design practice and helped strengthen my understanding of digital hardware design and Verilog coding.
